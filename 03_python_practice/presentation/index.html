Сериализация: JSON и Словари

JSON (строка) и Словарь (объект в ОЗУ) похожи, но имеют строгие отличия:

  • В JSON строки только в двойных кавычках: "key".
  • Логические значения: в JSON — true/false/null, в Python — True/False/None.
Любая опечатка в JSON вызывает ошибку json.JSONDecodeError. Обязательно используем try-except! 
import json

# Парсим JSON-строку в словарь
data = json.loads('{"active": true}')
print(data["active"])  # True

# Сериализуем обратно в строку
raw = json.dumps(data, ensure_ascii=False)
# '{"active": true}'

Время в вебе: модуль datetime

  • Даты передаются по сети строками (ISO 8601).
  • strptime() — преобразует строку времени в объект datetime по шаблону.
  • strftime() — преобразует объект в красивую строку.
  • timedelta — хранит длительность интервала.
Формула пересечения:
Два интервала [S1, E1] и [S2, E2] пересекаются, если:
S1 < E2 and S2 < E1 (без учета стыков) 
from datetime import datetime, timedelta

fmt = "%Y-%m-%d %H:%M"
start = datetime.strptime("2026-06-26 12:00", fmt)

# Прибавим 2 часа
end = start + timedelta(hours=2)
print(end.strftime("%H:%M"))  # 14:00

# Длительность в часах
diff = end - start
hours = diff.total_seconds() // 3600

Валидация запросов: Безопасность

Никогда не верьте клиенту. Все входящие данные должны проверяться.

Что нужно проверить:

  • Наличие полей — не забыл ли клиент пароль/email?
  • Тип данных — возраст должен быть числом, а не текстом "17 лет".
  • Формат значений — почта должна содержать @ и ., логин — быть латинским.
Хороший API в ответ на невалидный запрос возвращает статус 400 Bad Request и структурированный словарь с описанием ошибок для каждого поля.

URL-Router: Карта путей

  • Задача роутера — по входящему пути (например, /users/42/) найти нужную функцию-обработчик.
  • Сложность: поддержка динамических параметров типа <int:id>.
  • Решение: разбиваем шаблоны и реальные пути на списки сегментов по слэшу / и сопоставляем их поэлементно.
# Как это работает в Django:
path('users/<int:id>/', view_func)

# Как напишем мы:
@router.register("/users/<int:id>/", "GET")
def get_user(id):
    ...

Имитация СУБД: In-Memory CRUD

  • База данных должна сохранять состояние между запросами.
  • Для тестов идеально подходит хранилище в оперативной памяти (переменные класса).
  • Мы используем вложенные словари: {коллекция: {id: документ}}.
Внимание: Всегда используйте copy.deepcopy(), чтобы изменения в переданных словарях не меняли данные внутри БД! 
# Структура базы в ОЗУ
self._data = {
    "users": {
        1: {"id": 1, "name": "Иван"},
        2: {"id": 2, "name": "Анна"}
    }
}

Middleware: Цепочка посредников

  • Middleware — функция, которая оборачивает вызов основного обработчика.
  • Получает request и функцию next_handler.
  • Позволяет делать сквозные задачи:
    • Логирование (запись логов запросов).
    • Авторизация (проверка токенов).
    • Rate Limiting (ограничение спама).
Прерывание запроса: если middleware обнаруживает неверный токен, оно не вызывает next_handler, а сразу возвращает ответ 401 Unauthorized.
