Что такое HTML?

HTML (HyperText Markup Language) — это язык гипертекстовой разметки документов. Он сообщает браузеру, как именно нужно отображать контент (текст, картинки, кнопки).

Важно: HTML — это не язык программирования! В нем нет переменных, циклов или логических условий. Это язык разметки структуры данных.

Аналогия с домом:

  • HTML — бетонные блоки, балки, стены (каркас).
  • CSS — обои, краска, освещение (стиль).
  • JavaScript — лифт, водопровод, умный дом (поведение).

Каркас веб-страницы

Базовая структура HTML-документа

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, Квант!</h1>
    <p>Мы изучаем HTML5.</p>
</body>
</html>
  • <!DOCTYPE html> — объявление стандарта HTML5.
  • <html> — корневой элемент страницы.
  • <head> — метаданные (кодировка, заголовок вкладки, подключение стилей).
  • <body> — видимый контент страницы.
  • <meta charset="UTF-8"> — поддержка кириллицы.

Анатомия тега и атрибуты

Элемент состоит из открывающего тега, закрывающего тега и содержимого между ними:

<p class="lead">Привет, мир!</p>
  • Тег (Tag) — ключевое слово в угловых скобках (<p>).
  • Атрибут (Attribute) — дополнительные настройки тега в формате имя="значение" (class="lead"). Пишется только в открывающем теге.
  • Одиночные теги — не требуют закрывающего тега и не имеют содержимого:
    • <img src="pic.jpg" alt="Котик"> — изображение
    • <input type="text"> — поле ввода
    • <br> — перенос строки

Вложенность тегов и DOM-дерево

Теги могут быть вложены друг в друга, образуя иерархическую структуру дерева (DOM — Document Object Model):

<div class="container">
    <h2>Наши контакты</h2>
    <p>Напишите нам в <a href="#">Telegram</a>.</p>
</div>
Правило матрёшки: Вложенные теги должны закрываться строго в обратном порядке.
❌ <p>Привет <strong>Квант!</p></strong>
✅ <p>Привет <strong>Квант!</strong></p>

Виды элементов:

  • Блочные (Block) — занимают всю ширину родителя, начинаются с новой строки. Примеры: <div>, <p>, <h1>-<h6>, <form>.
  • Строчные (Inline) — занимают ширину только своего содержимого, не переносят строку. Примеры: <span>, <a>, <strong>, <em>, <input>.

Базовые текстовые теги

Тег Назначение Пример кода
<h1>–<h6> Заголовки уровней 1 (главный) – 6 (подподзаголовок) <h2>О лагере</h2>
<p> Абзац текста (блочный элемент) <p>Ура, лето пришло!</p>
<strong> Важный текст (обычно отображается жирным) <strong>Внимание!</strong>
<em> Логический акцент (курсив) <em>обязательно</em>
<code> Внутристрочный код (моноширинный шрифт) <code>print()</code>
<pre> Предварительно форматированный блок текста Сохраняет пробелы и переносы строк

Ссылки и изображения

Ссылки <a>

Позволяют переходить на другие ресурсы или страницы. Обязателен атрибут href.

<!-- Внешняя ссылка -->
<a href="https://kvant.ru" target="_blank">
    Сайт Кванта
</a>

<!-- Ссылка на внутренний файл -->
<a href="about.html">О нас</a>

Атрибут target="_blank" открывает ссылку в новой вкладке.

Изображения <img>

Одиночный тег. Требует атрибуты src (путь) и alt (текст при сбое загрузки).

<img src="images/logo.png" 
     alt="Логотип Кванта" 
     width="200">
Лайфхак: Всегда указывайте alt. Это важно для роботов Google/Yandex и для незрячих пользователей.

Списки в HTML

Маркированный список <ul>

Используется, когда порядок пунктов не важен. Элемент списка — <li>.

<ul>
    <li>Ноутбук</li>
    <li>Тетрадь</li>
    <li>Ручка</li>
</ul>

Нумерованный список <ol>

Используется для алгоритмов, шагов или топов. Порядковые номера проставляются автоматически.

<ol>
    <li>Встать</li>
    <li>Умыться</li>
    <li>Идти на лекцию</li>
</ol>

Семантическая разметка HTML5

Раньше всю структуру верстали тегами <div> с классами вроде class="header". Получался «div-суп», непонятный поисковикам.

HTML5 вводит семантические теги, которые сообщают браузеру и поисковым роботам смысловую роль каждого блока страницы.

Зачем это нужно:
  • SEO: Поисковые системы лучше индексируют сайт.
  • Доступность: Экранные дикторы (screen readers) зачитывают контент правильно.
  • Читаемость: Разработчик сразу видит структуру.
<header> (Шапка)
<nav> (Навигация)
<main> (Основное) <section>
<aside> (Сайдбар)
<footer> (Подвал)

Основные семантические элементы

  • <header> — вводный раздел страницы (логотип, название, профиль пользователя).
  • <nav> — блок навигационных ссылок (меню сайта).
  • <main> — основное уникальное содержимое страницы. На странице должен быть только один!
  • <section> — тематический раздел документа (например, блок «Схема проезда» или «Наши преподаватели»). Обычно содержит заголовок.
  • <article> — независимая, завершенная статья или новость, которую можно вырезать и вставить на другой сайт.
  • <aside> — косвенный контент (боковая панель, реклама, ссылки на другие статьи).
  • <footer> — подвал сайта (контакты, копирайты, ссылки на соцсети).

Введение в веб-формы: Тег <form>

Формы нужны для отправки пользовательских данных на сервер (регистрация, отправка сообщений, опросы).

<form action="/submit-form/" method="POST">
    <!-- Поля ввода находятся здесь -->
    <button type="submit">Отправить</button>
</form>

Ключевые атрибуты тега <form>:

  • action — URL-адрес сервера (в будущем — Django view), куда отправятся данные формы.
  • method — HTTP-метод передачи данных:
    • GET — параметры добавляются в адресную строку (для поиска).
    • POST — данные упаковываются в тело запроса (для паролей и личных данных).

Поле ввода <input>: Текстовые типы

Тег <input> является универсальным элементом ввода. Тип поля определяется атрибутом type.

<!-- Обычный текст -->
<input type="text" name="username">

<!-- Пароль (скрытые символы) -->
<input type="password" name="pwd">

<!-- Валидация почты -->
<input type="email" name="user_email">

<!-- Номер телефона -->
<input type="tel" name="phone">
Зачем указывать правильный тип?
  • Браузер автоматически проверяет валидность (например, есть ли символ @ в email).
  • На мобильных устройствах подменяется клавиатура (для type="tel" вылезут только цифры).

Числовые и интерактивные типы input

Тип Пример кода Дополнительные атрибуты
number (число) <input type="number" name="age"> min, max, step
range (ползунок) <input type="range" name="rating"> min="1" max="10" value="5"
date (календарь) <input type="date" name="birthday"> Полноценный выбор даты
color (палитра) <input type="color" name="theme"> Передает HEX-код цвета (например, #ff0000)
file (загрузка) <input type="file" name="avatar"> accept="image/*" (фильтр по типу)

Выбор вариантов: Checkbox и Radio

Флажки (Checkbox)

Позволяют выбрать несколько вариантов независимо друг от друга.

<input type="checkbox" name="hobbies" 
       value="coding" id="cb1">
<label for="cb1">Программирование</label>

<input type="checkbox" name="hobbies" 
       value="sports" id="cb2">
<label for="cb2">Спорт</label>

Переключатели (Radio)

Позволяют выбрать только ОДИН вариант из группы. Группа определяется общим атрибутом name.

<input type="radio" name="gender" 
       value="male" id="r1" checked>
<label for="r1">Мужской</label>

<input type="radio" name="gender" 
       value="female" id="r2">
<label for="r2">Женский</label>

Многострочный ввод и выпадающие списки

Поле ввода текста: <textarea>

Используется для длинных сообщений, отзывов, комментариев.

<textarea name="comment" 
          rows="4" 
          cols="40">
Стартовый текст...
</textarea>

Выпадающий список: <select>

Компактный выбор из фиксированного перечня вариантов <option>.

<select name="camp_unit">
    <option value="1">1-й отряд</option>
    <option value="2" selected>
        2-й отряд
    </option>
    <option value="3">3-й отряд</option>
</select>

Атрибуты управления и валидации

  • placeholder — полупрозрачная подсказка, исчезающая при начале ввода.
    <input type="text" placeholder="Введите имя...">
  • required — делает поле обязательным. Браузер не отправит форму без его заполнения.
    <input type="email" required>
  • value — задает начальное значение поля.
    <input type="text" value="Иван">
  • disabled — отключает поле (пользователь не может вводить и отправлять данные).
    <input type="text" disabled value="Заблокировано">
  • readonly — поле только для чтения (редактировать нельзя, но данные отправляются).
    <input type="text" readonly value="Только читать">

Кнопки в формах

Для создания кнопок в HTML используются теги <button> или <input>.

У тега <button> есть три основных типа (атрибут type):

  1. type="submit" — (по умолчанию в формах) собирает данные и отправляет форму.
  2. type="reset" — очищает все поля формы до их первоначального состояния.
  3. type="button" — просто кнопка. По нажатию ничего не происходит. Нужна для запуска JS скриптов.
<!-- Рекомендуемый подход -->
<button type="submit" class="btn">
    <img src="check.png" width="16">
    Зарегистрироваться
</button>

<!-- Альтернативный подход -->
<input type="submit" 
       value="Отправить">
Разница: Тег <button> может содержать внутри себя теги (изображения, жирный текст), а <input type="submit"> — нет.

Атрибуты Name и ID. Связь с Label

Атрибут name — это имя переменной, с которым значение инпута улетает на бэкенд. Без него Django не увидит данные!

Атрибут id — это уникальный идентификатор элемента на текущей странице (нужен для стилей, JS и связи с подписью).

Связь через <label>: клик по тексту подписи ставит фокус в поле ввода.

<!-- Правильная связь (через id) -->
<label for="user-age">Возраст:</label>
<input type="number" 
       id="user-age" 
       name="age">

<!-- Альтернативная вложенность -->
<label>
    Возраст:
    <input type="number" name="age">
</label>

Пример: Полная семантическая форма

<form action="/camp/register/" method="POST">
    <fieldset>
        <legend>Личные данные участника ЛФМШ «Квант»</legend>
        
        <label for="fio">ФИО:</label>
        <input type="text" id="fio" name="fullname" required placeholder="Иванов Иван">

        <label for="spec">Направление:</label>
        <select id="spec" name="track">
            <option value="math">Математика</option>
            <option value="phys">Физика</option>
            <option value="code" selected>Программирование (Django)</option>
        </select>

        <button type="submit">Подать заявку</button>
    </fieldset>
</form>

Резюме и переход к практике!

  • HTML5 организует разметку с помощью тегов, задающих структуру веб-документа.
  • Семантика (<main>, <section> и т.д.) делает код понятным для поисковиков и скринридеров.
  • Формы передают данные на бэкенд по протоколам GET и POST.
  • Атрибут name критически важен — это ключ данных при обработке сервером.
