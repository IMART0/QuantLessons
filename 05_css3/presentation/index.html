Зачем нам CSS3?

CSS3 (Cascading Style Sheets) — это язык стилей, который превращает сырую HTML-разметку в красивый веб-интерфейс.

  • Отделяет структуру документа от его внешнего вида.
  • Позволяет создавать адаптивные сетки под любые экраны.
  • Добавляет анимацию, тени, скругления и градиенты.

Аналогия

Если HTML — это кирпичные стены и каркас здания, то CSS — это внешняя отделка, дизайн интерьера, цвет обоев и расстановка мебели.

Базовые селекторы CSS

Селекторы указывают, к каким элементам применить стили:

  • По тегу: выбирает все элементы указанного тега. 
    p { color: red; }
  • По классу (.): выбирает элементы с данным классом. 
    .btn { padding: 10px; }
  • По ID (#): уникальный элемент на странице. 
    #header { background: blue; }
  • Универсальный селектор (*): все элементы. 
    * { box-sizing: border-box; }
  • Группировка: стили для нескольких селекторов. 
    h1, h2, h3 { font-family: sans-serif; }

Связи между селекторами (Комбинаторы)

Как стилизовать элементы в зависимости от их взаимного расположения в DOM-дереве:

  • Потомок (пробел): Выбирает всех детей, внуков и т.д. 
    div p { color: green; } /* Любой p внутри div */
  • Дочерний селектор (>): Выбирает только непосредственных детей (первый уровень). 
    ul > li { list-style: none; }
  • Соседний селектор (+): Выбирает первый элемент сразу ПОСЛЕ указанного (на одном уровне). 
    h1 + p { font-weight: bold; } /* p сразу после h1 */
  • Родственный селектор (~): Выбирает все элементы после указанного на одном уровне. 
    h1 ~ p { color: gray; } /* Все p после h1 на том же уровне */

Псевдоклассы и псевдоэлементы

Псевдоклассы (состояние элемента)

  • :hover — при наведении курсора.
  • :focus — когда элемент в фокусе (например, инпут).
  • :active — в момент клика.
  • :nth-child(n) — выбор по порядковому номеру (например, :nth-child(2n) для четных).

Псевдоэлементы (виртуальный контент)

  • ::before — вставляет контент перед содержимым элемента.
  • ::after — вставляет контент после содержимого элемента. 
    .required::after {
  content: " *";
  color: red;
}

Каскадность и Специфичность (Specificity)

Если к одному элементу подходят разные правила, браузер рассчитывает их «вес»:

Компонент Пример Вес
Inline-стиль style="..." 1000
Идентификатор (ID) #header 100
Класс / Псевдокласс .btn / :hover 10
Тег / Псевдоэлемент div / ::before 1
Правило переопределения: При одинаковом весе побеждает правило, написанное в CSS-файле ниже.
!important: Ломает каскад, перебивая любые веса (использовать крайне осторожно!).

Блочная модель (Box Model)

Каждый HTML-элемент представляется браузером в виде прямоугольного бокса:

  • Content: сам текст или изображение (задается через width и height).
  • Padding (внутренний отступ): пространство между контентом и границей.
  • Border (рамка): линия вокруг контента и внутренного отступа.
  • Margin (внешний отступ): пустое пространство снаружи элемента, отделяющее его от соседей.
Margin (Внешний)
Border (Граница)
Padding (Внутренний)
Content (Контент)

Проблема размеров: Свойство box-sizing

content-box (по умолчанию)

Ширина элемента = width + padding + border.

/* Итоговая ширина = 300 + 40 + 4 = 344px! */
.box {
  width: 300px;
  padding: 20px;
  border: 2px solid;
}

border-box (современный стандарт)

Ширина элемента = в точности width. Отступы и границы «съедают» место внутри.

/* Итоговая ширина = ровно 300px! */
.box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid;
}
Рекомендуется всегда делать сброс в начале CSS: * { box-sizing: border-box; }

Что такое Flexbox?

CSS Flexible Box Layout (Flexbox) — это одномерный интерфейс раскладки, разработанный для выравнивания элементов по горизонтали или вертикали.

  • Одномерный: работает либо с одной строкой, либо с одной колонкой за раз.
  • Главная ось (Main Axis): ось, вдоль которой располагаются элементы (зависит от направления).
  • Поперечная ось (Cross Axis): перпендикулярна главной оси.

Как активировать?

Достаточно задать родителю свойство:

.container {
  display: flex;
}

Направление и перенос во Flexbox

flex-direction (Направление оси)

  • row (дефолт) — слева направо.
  • row-reverse — справа налево.
  • column — сверху вниз.
  • column-reverse — снизу вверх.

flex-wrap (Перенос строк)

  • nowrap (дефолт) — сжимать элементы, чтобы они влезли в одну строчку.
  • wrap — переносить невлезающие элементы на новую строку.
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap; /* Сокращенно: flex-flow: row wrap; */
}

Выравнивание по главной оси: justify-content

Определяет, как распределяется свободное пространство вдоль главной оси:

  • flex-start — элементы прижаты к началу строки.
  • flex-end — прижаты к концу строки.
  • center — по центру.
  • space-between — крайние элементы прижаты к краям, пространство распределено равномерно между ними.
  • space-around — равное пространство вокруг каждого элемента.
  • space-evenly — равные отступы между всеми элементами и краями.
.container {
  display: flex;
  justify-content: space-between; /* Элементы «разлетятся» по краям */
}

Выравнивание по поперечной оси

align-items (выравнивание в строке)

  • stretch (дефолт) — растянуть на всю высоту контейнера.
  • flex-start — прижать к началу поперечной оси.
  • flex-end — прижать к концу.
  • center — выровнять по центру.
  • baseline — выровнять по базовой линии текста.

align-content (между строками)

Работает только при многострочном режиме (flex-wrap: wrap), распределяет пространство между строками аналогично justify-content.

Свойства Flex-элементов (Items)

Задаются дочерним элементам внутри flex-контейнера:

  • flex-grow: Коэффициент роста (доля от свободного места). По умолчанию 0.
  • flex-shrink: Коэффициент сжатия при нехватке места. По умолчанию 1.
  • flex-basis: Базовый размер элемента перед распределением места.
  • flex: Короткая запись для grow shrink basis (например, flex: 1 1 auto;).
  • align-self: Переопределяет align-items для отдельного элемента.
  • order: Позволяет менять визуальный порядок элементов без изменения HTML.

Что такое Grid Layout?

CSS Grid Layout — это двумерная сетка (колонки + строки). Идеальна для построения макетов крупных страниц.

Главное отличие от Flexbox

  • Flexbox: одномерный (верстаем либо строками, либо колонками).
  • Grid: двумерный (управляем строками и колонками одновременно).

Как активировать?

.grid-container {
  display: grid;
}

Создание сетки: Колонки и строки

Размеры колонок и строк:

  • grid-template-columns — ширина колонок.
  • grid-template-rows — высота строк.
  • fr — фракции (свободные части пространства).
/* 3 колонки: 1-я 200px, остальные делят остаток 1:2 */
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 2fr;
}

Полезные функции:

  • repeat(кол-во, размер) — автоповтор.
  • minmax(min, max) — адаптивный размер.
/* 3 колонки одинаковой ширины */
grid-template-columns: repeat(3, 1fr);

/* Адаптивная автосетка */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Отступы и Позиционирование элементов в Grid

Промежутки (Gap)

Свойство gap (или row-gap и column-gap) задает расстояние между ячейками без использования margin.

.grid {
  display: grid;
  gap: 20px; /* Отступы по 20px */
}

Управление элементом

Вы можете растянуть элемент на несколько ячеек по номерам линий сетки:

.grid-item-wide {
  grid-column: 1 / 3; /* От 1-й линии до 3-й */
}
.grid-item-span {
  grid-column: span 2; /* Растянуть на 2 ячейки */
}

Адаптивная верстка и Viewport

Сайт должен отлично выглядеть как на мониторе 4K, так и на экране смартфона.

Для корректного масштабирования на мобильных устройствах всегда прописывайте этот тег в <head>:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Без этого тега:

Смартфон симулирует экран настольного компьютера (~980px) и сжимает весь сайт до крошечного масштаба, делая его нечитаемым.

Медиа-запросы (@media)

Позволяют применять CSS-правила выборочно, в зависимости от ширины экрана:

/* Базовые стили (например, для мобильных) */
.content {
  flex-direction: column;
}

/* Стили для экранов шире 768px */
@media screen and (min-width: 768px) {
  .content {
    flex-direction: row;
  }
}

Mobile First подход

Сначала пишем стили под мобильные (простые, в одну колонку), затем расширяем интерфейс с помощью min-width по мере роста экрана.

Пример: Адаптивная карточка товара

/* Карточка товара с использованием flexbox */
.product-card {
  display: flex;
  flex-direction: column; /* По умолчанию в колонку на мобильных */
  border: 1px solid #ccc;
  padding: 15px;
}

@media screen and (min-width: 600px) {
  .product-card {
    flex-direction: row; /* В ряд на больших экранах */
    align-items: center;
  }
  .product-image {
    margin-right: 20px;
    width: 150px;
  }
}

Резюме и практические задания

  • Селекторы: точечно находят нужные элементы.
  • Box Model: основа позиционирования (используем border-box).
  • Flexbox: идеален для выравнивания вдоль одной линии.
  • Grid Layout: лучший выбор для двумерных сеток.
  • @media: делает ваш интерфейс адаптивным.
  • Mobile First: начинаем верстку с мобильных экранов.
