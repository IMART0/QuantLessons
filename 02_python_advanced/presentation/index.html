Гибкие параметры: *args и **kwargs

Позволяют передавать произвольное количество аргументов в функцию:

  • *args собирает все лишние позиционные аргументы в кортеж (tuple).
  • **kwargs собирает все лишние именованные аргументы в словарь (dict).
def process_request(route, *args, **kwargs):
    print("Маршрут:", route)
    print("Позиционные:", args)   # tuple
    print("Именованные:", kwargs) # dict

Обратная операция

Одиночная звездочка * и двойная ** при вызове функции используются для распаковки кортежей/списков и словарей в аргументы.

Где это применяется в вебе?

Используется для построения промежуточного ПО (Middleware), декораторов и гибких оберток:

# Пример: Универсальная обертка для отправки API-ответов
def send_response(status_code=200, *args, **kwargs):
    response = {
        "status": "success" if status_code < 400 else "error",
        "data": args,          # Позиционные аргументы запишем в список
        "meta": kwargs         # Именованные аргументы — метаданные ответа
    }
    return response

# Вызов:
send_response(201, "User created", "ID: 42", ip="127.0.0.1", time="0.05s")
# { 'status': 'success', 'data': ('User created', 'ID: 42'), 
#   'meta': {'ip': '127.0.0.1', 'time': '0.05s'} }

Лямбда-функции: однострочный код

Лямбда-функция — это короткая анонимная функция, состоящая из одного выражения.

# Синтаксис: lambda аргументы: выражение

# Обычная функция:
def square(x): return x ** 2

# Эквивалентная лямбда:
sq = lambda x: x ** 2

Применение в вебе: сортировка и фильтрация списков по сложным ключам (например, сортировка товаров по цене/рейтингу).

products = [
    {"name": "Laptop", "price": 800},
    {"name": "Phone", "price": 500},
]
# Сортировка по цене:
sorted_prod = sorted(
    products, 
    key=lambda item: item["price"]
)

ООП: Классы, Объекты и Инкапсуляция

Веб-сервис оперирует объектами реального мира: Пользователь, Заказ, Статья.

  • Инкапсуляция объединяет данные и методы их обработки, скрывая детали.
  • Приватные поля начинаются с двух подчеркиваний (__password).
  • Декоратор @property создает контролируемый доступ к полям (геттеры/сеттеры).

Пример User:

class User:
    def __init__(self, email):
        self._email = email # protected
    
    @property
    def email(self):
        return self._email.lower()

Наследование и Полиморфизм в Django и API

Наследование: Создание специализированных классов на основе базовых (в Django так создаются все модели и представления).

class BaseResponse:
    def render(self): return "Base body"

class JSONResponse(BaseResponse):
    def render(self): return '{"status": "ok"}' # Полиморфизм: переопределение метода

class HTMLResponse(BaseResponse):
    def render(self): return "
Hello!
"

# Полиморфизм: один интерфейс (render), разное поведение
def send_to_client(response_obj):
    print(response_obj.render()) # Вызовет правильный метод для каждого класса

Магические методы (Dunder Methods)

Начинаются и заканчиваются на двойное подчеркивание. Управляют встроенным поведением объектов.

  • __init__(self, ...) — конструктор объекта.
  • __str__(self) — строковое представление объекта (для пользователей, print, логов).
  • __repr__(self) — представление для отладки и разработчика.
class DBConnection:
    def __init__(self, db_name):
        self.db = db_name
    def __str__(self):
        return f"Соединение с БД '{self.db}'"
    def __repr__(self):
        return f"DBConnection('{self.db}')"

conn = DBConnection("users_db")
print(conn) # Соединение с БД 'users_db'

Декораторы: Теория и Замыкания

Декоратор — это функция, которая принимает другую функцию в качестве аргумента, модифицирует её поведение и возвращает новую функцию.

  • В основе лежат функции высшего порядка (передаются как переменные) и замыкания (closures).
  • Позволяет повторно использовать код без изменения самих функций.

Аналогия с оберткой

Декоратор — это подарочная коробка. Вы кладете туда вещь (функцию), добавляете бантик (код до и после) и отдаете обратно.

Пишем свой декоратор: Замер времени

import time

def timing_decorator(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs) # Выполняем исходную функцию
        end = time.time()
        print(f"Функция {func.__name__} выполнилась за {end - start:.4f} сек.")
        return result
    return wrapper

@timing_decorator
def fetch_api_data():
    time.sleep(1.5) # Имитация сетевого запроса
    return {"status": "done"}

Работа с датами и временем (datetime, time)

В веб-сервисах время критически важно: создание сессий, постов, транзакций.

  • Проблема часовых поясов: Храните время всегда в UTC, а на клиенте показывайте локально.
  • datetime.now(timezone.utc) — получение текущего времени UTC.
  • Парсинг: strptime (из строки в дату) и форматирование: strftime (из даты в строку).
from datetime import datetime, timezone

# Текущее время в UTC
now = datetime.now(timezone.utc)
print(now.isoformat()) 
# 2026-06-22T00:46:07+00:00

# Из строки в объект
d = datetime.strptime(
    "2026-06-22 10:00", 
    "%Y-%m-%d %H:%M"
)

Регулярные выражения (Модуль re)

Шаблоны для поиска и валидации текста. Импортируются через import re.

  • re.match(pattern, string) — проверяет совпадение с начала строки.
  • re.search(pattern, string) — ищет первое совпадение в любом месте строки.
  • re.findall(pattern, string) — находит все совпадения.
  • re.sub(pattern, repl, string) — заменяет совпадения.

Базовый синтаксис:

  • \d — цифра, \w — буква/цифра.
  • + — 1 или более, * — 0 или более.
  • ^ — начало строки, $ — конец строки.

Где Regex применяется в вебе?

1. Валидация входных данных: Проверка корректности Email, телефонного номера, надежности пароля.

2. Парсинг URL-адресов: Маршрутизация запросов (выделение ID статьи из адреса /post/(\d+)/).

# Валидация email
email_pattern = r"^[\w\.-]+@[\w\.-]+\.\w+$"
email = "student@kvant.ru"

if re.match(email_pattern, email):
    print("Email корректен")
else:
    print("Неверный формат")
